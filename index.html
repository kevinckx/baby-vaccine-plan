iPhone 订阅方法

  1. 点击下方 「一键订阅（iPhone）」 按钮
  2. 系统弹出「要订阅日历吗？」，点击 「订阅」
  3. 打开「日历」App 即可看到所有疫苗日程

安卓手机订阅方法

  1. 复制上方链接
  2. 打开 Google 日历 → 设置 → 添加日历 → 通过 URL 订阅
  3. 粘贴链接并确认

电脑订阅方法

  1. macOS 日历：菜单 → 文件 → 新建日历订阅 → 粘贴链接
  2. Outlook：添加日历 → 从 Internet → 粘贴链接
